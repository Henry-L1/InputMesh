# Code of Conduct

## Our pledge

We pledge to make participation in InputMesh a harassment-free experience for
everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

## Expected behavior

- Be respectful, constructive and patient.
- Focus criticism on ideas and code, not people.
- Respect privacy and do not publish sensitive security details.
- Accept responsibility, apologize for mistakes and learn from them.

Harassment, threats, discriminatory language, deliberate intimidation,
doxxing, sexualized attention and sustained disruption are not acceptable.

## Enforcement

Repository maintainers may edit or remove contributions that violate this code
and may temporarily or permanently restrict participation. Report conduct
issues privately to the repository owner through GitHub. Maintainers will
handle reports as confidentially as practical and will avoid conflicts of
interest when reviewing them.

This code applies in project spaces and when someone publicly represents the
project.
