# 软件工程计划

## 工作流总表

| 阶段 | 交付物 | 退出条件 |
|---|---|---|
| 0. 需求与选型 | 需求基线、开源/许可证调查、威胁模型 | 明确 Windows/macOS、局域网、屏幕粒度和单控制者语义 |
| 1. 可运行骨架 | Tauri 2 双平台工程、React UI、CI | macOS/Windows 均通过编译、测试和静态检查 |

| 3. 屏幕拓扑 | 显示器枚举、画布拖拽、启用开关、持久化 | 混合分辨率/负坐标/断连重连测试通过 |

| 6. 发布 | 签名、公证、安装器、升级、隐私说明 | 两个平台干净机器安装/卸载/升级验收通过 |

## 第一版验收场景

1. 同一局域网的一台 Mac 与一台 Windows 电脑在 5 秒内互相显示。
2. 双方首次连接显示完全相同的 6 位码；任一方拒绝时不建立可信关系。
3. UI 能显示两端全部屏幕，拖动后的坐标在重启后保持。
4. 禁用某屏幕后，鼠标不能进入该屏；重新启用立即恢复。
5. 从任一端开始移动鼠标都能接管，远端注入事件不会反向形成事件风暴。
6. 键盘按下/抬起成对传输；断线时释放所有远端按键，避免“卡键”。
7. 网络断开、应用崩溃或按下紧急快捷键后，本机鼠标键盘立刻可用。
8. 100 Hz 指针事件下 p95 单向处理延迟低于 16 ms（有线 LAN）；旧移动事件允许合并，按键/按钮不可丢。

## 测试分层

- 单元测试：拓扑几何、协议序列化、配对码、帧尺寸、配置迁移。
- 属性/模糊测试：任意屏幕矩形和事件字节流不得 panic 或无界分配。
- 进程集成测试：一台机器启动两个隔离配置的节点，验证握手、信任和消息路由。
- 平台自动化：Windows 与 macOS CI 分别编译所有 `cfg` 路径。
- 真机测试：不同 DPI、多显示器、键盘布局、Wi-Fi/有线、休眠唤醒、防火墙和权限撤销。
- 发布测试：未签名开发包、已签名发行包、升级与完全卸载。
